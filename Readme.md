📌 About the Project

Image Editor is a browser-based image editing tool that allows users to upload images and apply multiple filters in real time.
The project focuses on core frontend fundamentals, including:

DOM manipulation

CSS filter() usage

Real-time UI updates

Scalable CSS architecture using variables

It’s fast, simple, and beginner-friendly.

✨ Features

✅ Upload images from local device
🎚️ Real-time filter adjustments
🎨 Supported filters:

Brightness

Contrast

Saturation

Hue Rotation

Blur

Grayscale

Sepia

Opacity

🔄 Reset filters instantly
⚡ Smooth live preview
🖥️ Fully frontend (no backend, no dependencies)

This ensures consistency, scalability, and easy customization across the UI.

Theme Variables


🧠 How It Works

Image effects are applied using CSS filter()

Each filter has:

Default value

Minimum & maximum range

Unit (%, deg, px)

Slider inputs update styles instantly for real-time feedback

This approach keeps performance fast and code simple.
